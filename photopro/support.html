How do I start?

Choose Add Photo Folder in the welcome screen, or press ⌘O. PhotoPro scans subfolders too. In the sidebar, choose a folder, favorites or a star rating. Choose All Photos to clear the filters.

Which files can I open?

JPEG and other formats supported by macOS Image I/O, including supported RAW camera files. A same-name RAW is paired with its JPEG and hidden from the strip. Camera and OS versions determine RAW compatibility; not every listed extension is decodable.

Do edits change my original?

Cropping, filters and export create a new PNG. Crops are kept per image for this app session only; export before quitting. Filters reset when you change photographs. PNG exports go to Downloads and receive a numeric suffix if a name is already used.

What happens when I delete or unfavorite?

D or Delete works only while viewing a photo. The original goes to Trash or a nearby _PhotoPro_Deleted folder. Paired RAW deletion is on by default; change it in the sidebar. ⌘Z restores recent operations in this session. Unfavoriting moves only that original’s mapped copy. Originals are not deleted by unfavoriting.

Where are favorites stored?

The App Store build starts with a Favorites folder inside its private application support container. Use Open Favorites Folder or Choose Favorites Folder in the sidebar. Local developer builds retain the Pictures/PhotoPro Favorites location. Legacy copies are preserved, but need to be favorited again to establish unambiguous source mappings.

How do I use a NAS or restore access?

Connect the server in Finder, then select its mounted folder with PhotoPro’s system folder picker. Re-add a source if access expires or a disk moves. Passwords stay with macOS. Network availability and filesystem permissions affect reading, copying and restoring files.

How do I clear my local records?

Open About PhotoPro → Usage & Support → Reset Local Library Records. Sources, saved folder permissions, ratings, favorite mappings, crops and preferences are cleared. Original, favorite and exported files remain for you to manage in Finder.

如何开始？

在欢迎页点击“添加照片文件夹”，或按 ⌘O。应用会扫描子文件夹。侧栏可按文件夹、收藏或星级筛选；“全部照片”会清除筛选。

支持哪些图片？

支持 macOS Image I/O 可读取的 JPEG、其他图片及部分相机 RAW。与 JPEG 同名的 RAW 会配对并从缩略图条隐藏。RAW 是否可读取决于系统和相机格式，并非所有已列出的扩展名都保证能解码。

编辑会改动原图吗？

裁切、滤镜与导出会生成新的 PNG。裁切按照片保留到本次应用退出，请及时导出；滤镜换图后复位。新文件保存到下载文件夹，重名时自动添加数字后缀。

删除和取消收藏有什么区别？

D / 删除键只在看图模式下生效，原图移至废纸篓或旁边的 _PhotoPro_Deleted 文件夹。默认连同同名 RAW，可在侧栏关闭。⌘Z 在本次会话中撤销最近操作。取消收藏只移动对应的收藏副本，不会删除原图。

收藏保存在哪里？

App Store 版本默认保存在应用私有支持目录内的 Favorites 文件夹；可在侧栏打开或更换收藏文件夹。本机开发版本沿用“图片/PhotoPro Favorites”。旧版副本保留，但需要重新收藏以建立明确的原图对应关系。

NAS 或文件夹权限失效怎么办？

先在 Finder 连接服务器，再通过 PhotoPro 系统文件选择器添加挂载目录。权限失效或磁盘路径变化时，重新添加来源。认证密码由 macOS 管理；网络和文件系统权限会影响读取、复制和恢复操作。

如何清除本机记录？

打开“关于 PhotoPro → 使用与支持 → 重置本机图库记录”。来源、访问书签、星级、收藏对应关系、裁切和偏好会清除。原图、收藏副本和导出文件保留，由你在 Finder 中管理。
