每日学习如何使用？

“今日”每天按设备本地日期选出五条内容。同一天的选词保持一致。先回想表达，再点击“查看讲解”，读完后点“学废了！”记录完成。

如何收藏和搜索？

轻点词条右上角书签即可收藏。在“发现”或“收藏”中输入英文单词、中文含义或例句关键词，并通过分类菜单缩小范围。

朗读没有声音？

检查设备音量及音频输出设备。学废了 使用 Apple 系统英语语音；可在系统辅助功能的语音设置中检查可用语音。朗读不需要麦克风权限。

换机时怎么保留进度？

在旧设备的 学废了 设置中选择“导出学习记录”，将 JSON 文件保存到你选择的位置。在新设备中选择“导入学习记录”。导入将替换现有记录，操作前可先另存一份备份。

如何反馈内容错误？

请注明词条标题、有问题的句子，以及你参考的用法或资料。表达是否自然会随语境、地区和交流对象变化，我们欢迎具体的例子。

报告应用问题

请尽可能说明设备型号、iOS 版本、学废了 版本、复现步骤及截图。无需发送 Apple ID 密码、验证码或任何 API Key。
